## PFO1 - Landing de portafolio personal

Landing de portafolio personal desarrollada para la Práctica Formativa Obligatoria 1 de la materia Desarrollo de Sistemas Web: Frontend.

El sitio presenta mi perfil como estudiante de Desarrollo de Software, las tecnologías que estoy aprendiendo, mi forma de trabajo y un medio de contacto mediante GitHub.

## Tecnologías utilizadas

- HTML5.
- CSS3.
- Google Fonts.
- Flexbox.
- CSS Grid.
- SVG.
- Git y GitHub.
- Vercel.

## Características

- Estructura HTML semántica con `header`, `nav`, `main`, `section` y `footer`.
- Navegación interna entre las distintas secciones.
- Presentación personal y descripción de habilidades.
- Tarjetas organizadas mediante CSS Grid.
- Formulario con etiquetas `label`.
- Enlace visible y funcional al perfil de GitHub.
- Diseño responsive para computadoras, tablets y teléfonos.
- Transiciones y animaciones creadas con CSS.
- Ilustración SVG con texto alternativo.
- Estados de foco visibles y enlace para saltar al contenido principal.
- Compatibilidad con la preferencia `prefers-reduced-motion`.

## Decisiones de diseño

Elegí un estilo claro y moderno, con una combinación de azul, verde azulado, blanco y tonos oscuros para mantener un contraste adecuado.

Utilicé la tipografía Manrope desde Google Fonts porque ofrece una apariencia contemporánea y buena legibilidad en diferentes tamaños de pantalla.

La navegación, los botones y el pie de página se organizaron con Flexbox. Las secciones principales y las tarjetas de habilidades se maquetaron con CSS Grid. La combinación de ambas tecnologías permitió adaptar el contenido a distintas resoluciones.

Se incorporaron variables CSS para conservar la coherencia de colores, sombras, bordes y medidas. También se agregaron puntos de quiebre para reorganizar las columnas y los botones en tablets y teléfonos.

El formulario no almacena información ni envía mensajes. Su botón abre mi perfil de GitHub, que es el único medio de contacto público elegido para esta actividad.

## Uso de inteligencia artificial

### Herramienta y plan

Utilicé ChatGPT de OpenAI mediante el plan ChatGPT Plus (pago).

### Finalidad de uso

La herramienta se utilizó para:

- Interpretar y organizar los requisitos de la consigna.
- Planificar la estructura semántica del documento HTML.
- Recibir orientación paso a paso sobre GitHub Desktop y Vercel.
- Proponer una base para los estilos CSS responsive.
- Crear la ilustración SVG utilizada en la presentación.
- Revisar la accesibilidad, los enlaces y la adaptación a dispositivos móviles.
- Mejorar la documentación del proyecto y los mensajes de los commits.

### Experiencia previa

Antes de esta actividad ya había utilizado ChatGPT para recibir orientación, organizar ideas y revisar contenidos. Sin embargo, tenía experiencia inicial en la creación y publicación completa de una landing de portafolio con HTML, CSS, GitHub y Vercel.

### Revisión y adaptación con criterio propio

Leí la consigna completa y revisé cada parte sugerida antes de incorporarla. Decidí presentar únicamente mi perfil como estudiante de Desarrollo de Software, utilizar un estilo claro y moderno y mantener GitHub como único medio de contacto público.

Creé y organicé manualmente los archivos del proyecto, corregí la ubicación de las carpetas, eliminé etiquetas HTML duplicadas y verifiqué la estructura semántica. También comprobé la visualización en escritorio y en una pantalla móvil de 390 píxeles.

La ilustración SVG fue creada con asistencia de ChatGPT y luego revisada visualmente antes de incorporarla. Los textos, colores, secciones y decisiones finales fueron seleccionados y validados de acuerdo con la consigna.
